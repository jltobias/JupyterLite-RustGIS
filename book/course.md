# Notebook course

The [Lab](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=00_start_here.ipynb) contains ten browser lessons. The first three notebooks include executable analyses, visualizations, and exercises.

| Lesson | Question | Main artifact |
| --- | --- | --- |
| [00 Start here](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=00_start_here.ipynb) | Where does each component run? | Course route and runtime diagram |
| [01 Explore GeoJSON](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=01_explore_geojson.ipynb) | What can we check before mapping? | Extent, schema, schematic map, chart |
| [02 Map links](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=02_map_links.ipynb) | How does perspective change inference? | 2D/3D/RustGIS comparison |
| [03 RustGIS bridge](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=03_rustgis_bridge.ipynb) | What belongs in a data handoff? | GeoJSON and provenance manifest |
| [04 WorldPop STAC](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=04_stac_worldpop.ipynb) | What does an Item footprint show? | Metadata chart and RustGIS handoff |
| [05 STAC catalogs](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=05_stac_catalogs.ipynb) | How do bounded queries travel across APIs? | Optional live provider search |
| [06 Climate scenarios](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=06_climate_scenarios.ipynb) | Is a table ready to map? | Scenario and decade charts |
| [07 Ollama assistance](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=07_ollama_assistance.ipynb) | How do we inspect an AI map plan? | Typed, validated proposal |
| [08 Globe and scene](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=08_globe_and_scene.ipynb) | What do perspective and projection hide? | Four-view comparison |
| [09 Capstone](https://jltobias.github.io/JupyterLite-RustGIS/lab/lab/index.html?path=09_capstone.ipynb) | Can another analyst reproduce the claim? | STAC brief, GeoJSON, source query |

The [native RustGIS notebook](https://github.com/jltobias/JupyterLite-RustGIS/blob/main/notebooks/04_native_rustgis.ipynb) is a local Python lesson with a `Session`, PNG export, and buffer operation. It is separate from the Pyodide course.
