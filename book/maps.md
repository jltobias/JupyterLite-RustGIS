# Maps and scenes

| View | What to inspect |
| --- | --- |
| [2D map](https://jltobias.github.io/JupyterLite-RustGIS/maps/2d.html) | Point locations and polygon footprints on an OpenStreetMap basemap. |
| [3D map](https://jltobias.github.io/JupyterLite-RustGIS/maps/3d.html) | Polygons extruded by their illustrative `height_m` values. Drag to rotate. |
| [3D scene](https://jltobias.github.io/JupyterLite-RustGIS/maps/scene.html) | The same features in a pitched view with stronger perspective. |

The 2D and extruded 3D maps use MapLibre GL JS. The standalone scene uses Three.js. For RustGIS's own maps, globe, and native analysis, use [RustGIS](https://github.com/opengeos/RustGIS) and its [browser app](https://web.rustgis.app/).
