# JupyterLite–RustGIS

![A stylized terrain globe](../assets/rustgis-splash.png)

This short book connects browser notebooks with 2D maps, extruded 3D maps, a 3D scene, and the upstream RustGIS application. The examples use a small, fictional teaching dataset around Washington, DC. Heights and categories are illustrative.

Start in the [JupyterLite Lab](https://jltobias.github.io/JupyterLite-RustGIS/lab/index.html), then read the [workflow](workflow.md) and compare the [map views](maps.md). For direct RustGIS use, open the [official web app](https://web.rustgis.app/) or run the [native notebook](https://github.com/jltobias/JupyterLite-RustGIS/blob/main/notebooks/04_native_rustgis.ipynb) locally.
